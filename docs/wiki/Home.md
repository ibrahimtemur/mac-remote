# 🍏 Welcome to the Mac Remote Wiki

**Mac Remote** is an open-source, zero-configuration remote control suite that turns your Android phone or tablet into a powerful wireless trackpad, keyboard, and presentation controller for macOS.

Whether you are presenting slides across a conference room, relaxing on your couch watching movies, or working remotely, Mac Remote provides instant control with low latency and native macOS integration.

---

## 🚀 Key Highlights

- **⚡ Instant Discovery (Zero Setup):** Automatic Mac server detection on local Wi-Fi via mDNS / Bonjour protocols.
- **🖐️ Natural Multi-Touch Gestures:** Precise cursor gliding, two-finger scrolling, right-click, double-click drag, and text selection.
- **🖥️ Real-time Screen Streaming:** Live desktop screen preview with variable adaptive quality (Low 800p up to Ultra 2200p).
- **⌨️ Integrated Keyboard & Shortcuts:** Full mobile keyboard input, space, backspace, enter, and special function keys.
- **🌐 Global Internet Access:** Optional built-in secure tunneling via Ngrok (`wss://`) for connecting outside your local network.
- **🔒 Privacy First:** All local communications stay within your LAN. No keystrokes or media data ever touch external third-party cloud servers.
- **🌐 Bilingual UI:** Full native support for both **English** and **Turkish (Türkçe)** with persistent language preferences.

## 📱 Supported Platforms
- **macOS Host:** macOS Monterey (12.0) or later (Apple Silicon M1/M2/M3/M4 & Intel).
- **Android Client:** Android 8.0 (Oreo / API 26) through Android 16 (API 36+), including tablets & foldable devices.
